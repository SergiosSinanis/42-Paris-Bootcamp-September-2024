# 42-School-Paris-Piscine-September-2024

Welcome to my 42 School Piscine repository! This repository contains all of the projects and exercises I completed during the 42 Paris Piscine. The Piscine is an intense, month-long coding bootcamp where students learn the fundamentals of C programming, problem-solving, and collaborative coding. It’s designed to challenge participants to push their limits, think critically, and adopt best practices in software development.
Through hands-on projects and challenges, I developed skills in low-level programming, data structures, memory management, and collaborative coding. Each project in this repository reflects a milestone in my journey at 42, showcasing solutions that highlight my logical thinking, coding practices, and perseverance.

Overview
The 42 School Piscine is a foundational program that prepares students for the main curriculum at 42. During the Piscine, I tackled various projects that required knowledge of:

C programming: mastering the syntax and structure of C, memory management, and pointers.
Unix and shell scripting: understanding Unix-based systems, basic shell commands, and scripting.
Algorithmic thinking: learning how to approach problems systematically and optimize solutions.
Each project pushed me to think critically and develop skills in debugging, optimizing code, and collaborating in a peer-driven learning environment.

Projects
Here’s a breakdown of the main projects and exercises included in this repository:

Rushes

Rush-00: Introduction to collaborative coding and basic output in C.

C Basics

C Exercises: A series of exercises covering C basics, including loops, conditionals, and functions.
Custom Functions: Recreating standard library functions (e.g., ft_putchar, ft_strlen, ft_strcmp) to understand low-level implementation.
Algorithms

Sorting and Searching: Implementing common algorithms and data manipulation techniques.
Recursion Exercises: Solving problems using recursion to deepen understanding of function calls and stack usage.
String Manipulation

ft_split: A function that splits a string into an array of words based on delimiters.

Advanced Challenges
Do-op: A calculator program that uses function pointers for operations.
Add Prime Sum: Calculating the sum of all prime numbers up to a given number.
PGCD: Finding the greatest common divisor of two integers.
Each folder in the repository corresponds to a specific day or project and includes all relevant source files, Makefiles, and README documentation as required by 42's guidelines.
